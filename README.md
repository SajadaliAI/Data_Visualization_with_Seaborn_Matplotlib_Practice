# 📊 Data Visualization with Seaborn & Matplotlib

This repository contains **lectures and practice exercises** for **Seaborn** and **Matplotlib** libraries in Python, focusing on creating beautiful and informative data visualizations.

---

## 🎯 Objective
- Learn Seaborn & Matplotlib from scratch  
- Practice plotting different charts: line, bar, histogram, scatter, heatmap, etc.  
- Understand customization: colors, styles, labels, legends
